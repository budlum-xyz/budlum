wallet-core in the browser

Signs a V5 (ML-DSA-87) transfer with the wasm build of crates/wallet-core and sends it to a node's public RPC Build the module first: 

cargo build --manifest-path crates/wallet-core/Cargo.toml --lib --release \
  --target wasm32-unknown-unknown --features wasm
wasm-bindgen --target web --out-dir crates/wallet-core/web/pkg \
  crates/wallet-core/target/wasm32-unknown-unknown/release/budlum_wallet_core.wasm

Serve this directory over HTTP and open the page. Use a test wallet only.
